# Platform status

## `0.0.1-preview.1`

- Unity package source baseline: Unity 2022.3 LTS.
- Demo project baseline: Unity 6.0.
- Node Bridge: authoring and validation only.
- Native Windows: boundary only; inference unavailable.
- Native macOS: not built.
- Native Linux: not built.
- Android and Quest: not built.

Do not advertise standalone or mobile support until the corresponding native
library, clean Unity import, player build, and launched-player checks pass.
