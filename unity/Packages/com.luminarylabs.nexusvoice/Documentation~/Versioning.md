# Versioning

NexusVoice uses semantic versions with preview identifiers.

- Small iteration: `0.0.1-preview.1` to `0.0.1-preview.2`.
- Meaningful compatible revision: `0.0.2-preview.1`.
- Major preview milestone: `0.1.0-preview.1`.
- Stable commercial API: `1.0.0`.

Published versions are never reused or decreased. Every release updates the package
manifest, both changelogs, release notes, archive names, and release tag.
