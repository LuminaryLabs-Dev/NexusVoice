# Unity Asset Store gate

Do not submit `0.1.0-preview.1` to the Asset Store yet. Linux x64 native synthesis
is technically validated, but publication still requires:

- Unity import, compile, tests, and standalone validation.
- A clean Linux standalone-player test and native inference for every other advertised platform.
- Formal review of the GPL-3.0-or-later eSpeak NG dependency and all third-party notices.
- Screenshots captured in Unity, audio previews, documentation, and support details.
