# itch preview gate

`0.1.0-preview.1` can be assembled as an internal Linux x64 technical-preview
archive. Its native mode does not require Node.js; the included Node engine is an
optional authoring and comparison tool.

Do not sell or publicly distribute this archive until the eSpeak NG integration
has passed formal legal review or has been replaced with a commercially compatible
phonemizer path. A public itch page also needs an honest Linux-only platform label,
installation instructions, complete license texts, checksums, audio samples, and a
clean-machine player test.
